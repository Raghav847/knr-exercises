# K&R Exercises

Solutions to exercises from *The C Programming Language* by Brian Kernighan and Dennis Ritchie (2nd Edition).

## Structure
knr-exercises/
├── ch01/   # Chapter 1
├── ch02/   # Chapter 2
├── ch03/   # Chapter 3
├── ch04/   # Chapter 4
├── ch05/   # Chapter 5
├── ch06/   # Chapter 6
├── ch07/   # Chapter 7
├── ch08/   # Chapter 8
├── Makefile
└── README.md

## Usage

Compile any exercise:
```bash
make ch01/ex1-1
```

Run it:
```bash
./ch01/ex1-1
```

## Requirements

- GCC
- Make
